# 其他爬虫缺陷测试记录

## Katana：未解析直接输入的 Source Map

| 项目 | 结果 |
|---|---|
| 测试日期 | 2026-11-18 |
| 工具 | `othercrawlers/katana.exe`，v1.8.0 |
| 目标 | `https://t-ciyuan.shdaex.com/static/js/index.js.map` |
| 测试结果 | `Crawl completed in 10s. 0 endpoints found.` |

### 复现命令

```powershell
.\othercrawlers\katana.exe `
  -u https://t-ciyuan.shdaex.com/static/js/index.js.map `
  -d 3 -jc -jsl -fs fqdn -mrs 30000000 -mdp 20 -rl 2 `
  -ct 45s -duc -j -or -ob -v
```

`-jc` 和 `-jsl` 均已启用；Katana 仍未从直接输入的 `.map` 文件中输出任何 endpoint。

### 缺陷说明

该目标 map 可正常访问，HTTP 状态为 200，响应类型为 `application/octet-stream`，大小约 12.8 MB，是 version 3 的 Source Map，包含 1,110 条 `sources`。因此，零输出不能归因于目标文件不存在或没有 `sources`。

在同一目标上，`basecrawler` 能从 map 的 `webpack://` 条目中提取 15 条路径；Katana v1.8.0 的直接 `.map` 输入测试没有提取这些路径。缺陷表现为：启用 JavaScript 解析选项，并不会让 Katana 自动解析 Source Map JSON 的 `sources` 字段。

这些 15 条路径主要是 webpack runtime 虚拟模块；请求后虽返回 200，内容却是 SPA HTML 回退页，并非真实源码。它们可用于验证解析行为，不应被当成有效源码 URL。

### 测试边界

本记录验证的是把 `.map` URL 直接作为 Katana 种子。尚未验证 Katana 是否会从普通 `.js` 文件中的 `sourceMappingURL` 注释发现并获取 map。
