# ✅ 符合要求：单静态二进制、跨平台、无头、对标 Lightpanda（CDP、原生自研内核，不是裁剪Chrome）
> Lightpanda 特点：Zig从零写、单文件、CDP协议、无头、主打AI/爬虫自动化，不做图形渲染

## 1. OxiBrowser（最贴近Lightpanda，优先推荐）
- 语言：Rust，**从零自研内核，不是Chromium分支**，JS引擎是 boa（纯Rust，不带V8）
- 包：**单静态二进制**，~21–44MB，Windows/macOS/Linux 全平台
- 协议：**兼容CDP**，直接给 Puppeteer / Playwright 替换使用
- 内存：基础约8MB，冷启动~50ms
- 协议：MIT，支持SSR防护、robots、指纹模拟
- 短板：WebAPI 兼容性比 Lightpanda 略弱，复杂前端、富交互页面容易翻车

## 2. Browser39
- 单二进制 ~52MB，Win/macOS/Linux
- 内置 Deno_core V8，支持JS执行，自带HTML转Markdown（面向LLM Agent很友好）
- 无外部依赖，不用装Chrome；CDP支持
- 适合：抓取、给大模型喂页面内容；交互能力一般

## 3. Navette-browser（极小体积，思路不一样）
- Rust单文件，**仅600KB～1.2MB**，超级小
- 原理：本身只是控制器，复用系统自带WebView（Windows WebView2 / macOS WebKit / Linux WebKit），**不是完整独立浏览器内核**
- 跨平台、单文件分发；CDP/自动化可用
- 缺点：依赖系统WebView环境，离线裸机、容器环境不一定能用；不能完全独立运行

## 4. Moli Browser
- 自研无头浏览器，Apache2.0，面向AI Agent，按需渲染
- 有单二进制分发包，CDP兼容
- 短板：生态和文档比Lightpanda/Oxi弱，版本迭代偏新，稳定性一般

## 5. Phasma
- Python打包单文件无头浏览器，跨平台 Win/macOS/Linux
- wheel包自带内核，不需要预装Chrome；~26MB
- 适合Python爬虫脚本；性能弱于上面几个原生二进制方案

---
# ❌ 不推荐（容易踩坑，不符合“单文件独立内核”）
- Browsh：单文件，但底层依赖Firefox，只是终端壳，不是独立浏览器引擎
- Miniblink：很小，但是偏嵌入式SDK，**没有标准CDP**，很难直接对接Playwright/Puppeteer
- Camoufox / undetected-chromedriver：本质还是Chromium打包，体积巨大，不是从零自研

# 📌 快速选型建议
- 想直接替换Lightpanda、跑Playwright/Puppeteer、独立内核：**OxiBrowser**
- 给LLM抓取页面、自动转Markdown：**Browser39**
- 本机桌面环境、极致小包、不介意依赖系统WebView：**Navette**
